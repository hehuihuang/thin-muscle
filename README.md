# thin-muscle · 薄肌网站首页视觉原型

「薄肌」健身生活方式网站的首页视觉原型：暗色 editorial 排版 + 酸性荧光绿点缀，超大中文标题。

## 预览

- 直接用浏览器打开 `index.html` 即可
- 或开启 GitHub Pages：Settings → Pages → Deploy from branch → 选择 `main` 分支 → `/ (root)`

## 文件结构

- `index.html` — 原型页面
- `assets/` — 图片资源

## 说明

此为视觉评审用原型。页面动效依赖 Anime.js CDN，需联网加载；断网时静态内容仍可正常浏览。
